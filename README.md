# PLAYER ONE — PlayStation Lounge

Responsive Georgian, English and Russian gaming lounge concept. Buildless static HTML, CSS and JavaScript in `dist/`.

## Preview
Serve `dist/` with any static server. No installation or build step is required.

## Behaviour
Game selection, remembered language, date validation in Tbilisi time, 1–4 players, illustrative per-console hourly estimate, and a copyable reservation request. The form does not send requests or reserve inventory. Connect the owner's actual contact channel before taking bookings.

## Demo information
Address follows the user's restaurant demo: Tbilisi, Africa, Machabeli 9. Rate is illustrative: GEL 10 per console per hour. Photography is illustrative and not a claim about a real venue. This independent concept is not affiliated with Sony.
